The desktop workspace is redrawn as a three-column development environment. The left column holds **Running Sessions** above a searchable **project/session tree**: every project, the sessions that run in it, a fold that never hides the session you are in, and a search that finds a session by name or first message. The middle column is the conversation with a compact header — the session title, its project, and **Settings** and **Actions** side by side — with **Subagents** under the header and **Background** and **Edited Files** above the composer, each collapsed until opened, each counting what the session actually reports. The right column is a persistent workbench with one tab strip: **Git**, **Files**, **Terminal**, **Goals**. The tab under the workbench is highlighted, a tab whose panel is missing stays visible and says why, and choosing a tab changes the panel without moving the conversation. **Info** and **Updates** moved into **Settings**, where Updates reports the versions the browser and the machine state and points at **Pi Packages** for the update itself. Below the desktop width the workbench keeps the same tabs and stacks under the session, so a tool page is never a dead end.

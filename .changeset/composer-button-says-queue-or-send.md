The composer's main button says on its face what the press does. While a task is
running it reads **Append to message queue** and queues the message, rather than
interrupting the turn the icon did not describe; on an idle session it reads
**Send**. Pressing it reads the session at the moment of the press, so a task that
finished a moment ago gets its message sent now. Enter still steers a running turn.

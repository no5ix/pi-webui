The interface is redrawn around the writing. **Chat** is no longer a stack of bordered cards: an assistant reply is prose on the canvas, capped at a 72-character reading measure so a line does not run to the far edge of a wide window (it ran to 148 characters before), your own message keeps a quiet bubble, and system, bash and tool notices are marked with a state rail instead of a box. Tool calls sit on dividers with the running, succeeded, failed and interrupted states on the rail, and code keeps its own darker surface. **Navigation** is a list you scan - one segmented control for Machines, Projects and Sessions, rows on hairlines, a row's path truncated inside the panel instead of running under its actions key and off a phone's edge. The **composer** becomes the one lifted surface on the screen with a single primary **Send** (a running turn gets a danger-toned stop), and the telemetry under it - tokens, context, branch, run time, cost, extension states - becomes a row of small chips that keeps each value's words whole, with the full precision in each chip's label. **Settings** is a document: a rail where the current section is filled rather than outlined, sections separated by a hairline instead of nested boxes, notices as rails, and theme tiles that show the look in use without a sentence.

The built-in interaction tokens are consumed by the composer sheen and selected navigation hover states, not merely published. The four built-in looks also stop shipping text a reader cannot read: secondary inks now clear WCAG AA for normal text on every surface they document, measured from 3.01:1 up to a lowest pair of 4.62:1. Plugin themes can supply a new set of optional interaction tokens - `--pi-accent-soft`, `--pi-accent-soft-hover`, `--pi-on-accent-soft`, `--pi-focus-ring`, `--pi-row-hover`, `--pi-divider`, `--pi-chip-bg`, `--pi-chip-border`, `--pi-code-bg`, `--pi-code-border`, `--pi-sheen` - and every one is derived when a theme omits it, so existing custom themes keep painting.
